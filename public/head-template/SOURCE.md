# Template source

MakeHuman hm08 basemesh, CC0.
Source: https://github.com/naver/anny/blob/main/src/anny/data/mpfb2/3dobjs/base.obj
License: LICENSE.md, retained unchanged from the same data directory.

The head is extracted and subdivided by scripts/prepare_head_template.py and scripts/fit_head_template.py. anchors.json contains approximate template registration points from the local frontal render, with symmetric neutral registration and corrected eye corner depth. The captured identity is not forced to be symmetric.
